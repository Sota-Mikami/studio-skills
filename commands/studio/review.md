# /studio:review — 批評的セルフレビュー

> **ループ内の位置**: 任意（P3 の後 / P4 の区切り / 出力前）。
> **いつ選ぶ**: 出力・共有の前に質を一段上げたい時。

対象（デザイン案 or 実装）を**批評的な目線**で点検する:

- **弱点を3つ以上**挙げる（凡庸・反証・リスク・ブランド禁則・アクセシビリティ）。「問題なし」で終わらせない。
- **受入基準カバレッジ**: `.studio/spec.md` の各基準を満たすか、**根拠付き**で確認（未達は明示）。
- repo に `impeccable` / `taste-skill` 等のデザイン skill があれば活用する。
- 直すべき点を**優先度付き**で列挙する（実行は別ステップ）。
